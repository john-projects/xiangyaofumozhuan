# 一、三座主城

## 广陵城 —— 中心主城

- **等级**：无（安全区）
- **简介**：前朝旧都。水巷纵横、园林清雅，处处透着褪色的气派。整片区域的地理与交通中心，所有线路都从这里出发。
- **地貌**：窄水巷、拱形石桥、白墙黑瓦民居、太湖石园林、跨街石牌坊、书院、老银杏、小画舫
- **配色**：旧铜、白墙、深瓦
- **连接**：芦花渡 / 落霞坡 / 落雁关 / 望海城 / 野狐关 / 幽冥泽
- **提示词**：`广陵城.txt`

## 临江城 —— 北城主城

- **等级**：无（安全区），北线终点
- **简介**：临江而建的繁华水陆商埠，城墙厚重，江岸停满货船。北线的最后一站，也是通往关隘与剑宗的门户。
- **地貌**：灰瓦城门楼、石板主街、木质栈桥码头、货船乌篷船、市集布棚、石拱桥、红灯笼、临江茶楼
- **配色**：暖灯笼金 + 江水青碧
- **连接**：黑风坳 / 剑鸣峰 / 落雁关（北线）
- **提示词**：`临江城.txt`

## 望海城 —— 海港主城

- **等级**：无（安全区），海路第一站
- **简介**：建在海崖之上的港口城市，城墙直面外海，城内石阶层层叠叠，码头停满渔船。
- **地貌**：崖上石阶街巷、直插海面的城墙垛口、木栈桥码头、渔船商船、渔网鱼干、灯塔望楼、海鲜市集、缆绳铁锚、水手客栈
- **配色**：海风青灰 + 渔火暖黄
- **连接**：广陵城 / 浮云岛（海路）
- **提示词**：`望海城.txt`

# 二、村庄与枢纽

## 桃花村 —— 出生点

- **等级**：无（安全区）
- **简介**：宁静美丽的沿海村庄，玩家的出生地。村中有五位门派掌门、商人和船夫。
- **地貌**：木结构青瓦民居、粉色桃花树与落花、青石板路、小木桥、晾晒渔网
- **连接**：芦花渡 / 桃林 / 桃花滩
- **提示词**：`桃花村.txt`

## 芦花渡 —— 野渡

- **等级**：无（安全区）
- **简介**：芦苇荡深处的一处野渡，只有一条木栈桥和一条渡船，是村庄通往广陵城的必经水路。
- **地貌**：齐人高苍白芦苇、歪斜木栈桥、平底渡船、断裂木路牌、泥滩车辙、破渔网、茅草棚
- **配色**：芦花白 + 灰绿水色
- **连接**：桃花村 / 广陵城
- **提示词**：`芦花渡.txt`

## 落雁关 —— 雄关（在用）

- **等级**：无（安全区 / 关卡）
- **简介**：两座山崖之间的雄关，关城依崖而建，有兵驻守，是北线通往高山区域的必经门户。
- **地貌**：石砌关城垛口、沿崖城墙、褪色朱红军旗、角楼箭楼、铁皮包门、石板官道、战鼓、火盆、哨塔烽燧
- **配色**：灰石 + 褪色朱红
- **连接**：广陵城 / 寒潭涧
- **提示词**：`落雁关.txt`

## 野狐关 —— 关隘（废弃）

- **等级**：无（危险区，无怪）
- **简介**：早已废弃的关隘，城门坍塌，城墙被荒草藤蔓吞没。通往栖霞山的旧路由此经过。
- **地貌**：坍塌关门、藤蔓残墙、歪挂锈铁门、烧毁角楼、裂开官道、倒塌石碑、狐形石雕、崖壁小破庙、浓雾
- **配色**：苔绿灰 + 锈铁
- **连接**：广陵城 / 栖霞山
- **提示词**：`野狐关.txt`

## 栖霞山 —— 山寺

- **等级**：无（半安全区）
- **简介**：秋日满山红枫的山，青石阶蜿蜒而上，半山有座小寺。
- **地貌**：盘山青石阶、红橙枫林、飞檐小山寺、崖壁题刻、观景亭、落叶、山涧小溪、青苔岩、小石塔、晨雾
- **配色**：枫红橙金 + 青灰岩
- **连接**：野狐关
- **提示词**：`栖霞山.txt`

## 桃花滩洞窟 —— 洞窟

- **等级**：无（低等级探索点）
- **简介**：桃花滩外的一处古代海蚀洞，空洞幽深，是新手期唯一的洞窟探索点。
- **地貌**：暗紫与霓虹蓝钟乳石、地下暗河、嶙峋岩壁、冥矿石晶体、诡异雾霭
- **连接**：桃花滩
- **提示词**：`桃花滩洞窟.txt`

# 六、提示词与文件约定

每张地图一份提示词：`NN_<地图名>.txt`（NN = 抵达等级序号）

**结构**

```
【正文】主体描述 …，无背景，纯透明 --ar 4:3 --v 6.0

【画质】【机位】【背景】【负面】

移除此图像的背景。保持所有前景主体不变且完整，边缘干净平滑。将背景设为透明。
```

**文件命名**

```
NN_<地图名>.txt          提示词
NN_<地图名>-ai.png       生成的原图（1448×1086，4:3）
NN_<地图名>-无背景.png    去背后的成品
```

**共享规范**：`00_通用规范.txt`

> ⚠ 若出图背景变成灰白棋盘格，说明模型把"透明"当成了图案。
> 此时把【背景】改成：`主体独立存在于空白处，不画任何背景元素、无地面、无投影`
