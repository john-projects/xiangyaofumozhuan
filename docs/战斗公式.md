## 一、伤害曲线（梦幻西游口径）

战斗里**唯一的伤害入口**是 `BattleUnit.take_damage(amount, magic)`，普攻和技能最后都走它。

```gdscript
# ① 攻防差
var final := amount - guard          // guard = spell_defense（magic=true）或 defense
# ② 浮动 ±10%
final *= randf_range(0.9, 1.1)
# ③ 保底 / 封顶（相对本次原始伤害）
final = maxf(final, amount * 0.10)
final = minf(final, amount * 0.95)
# ④ 格挡值（固定减法，在保底之后）
final = maxf(1.0, final - stats.block_value)
# ⑤ 防御姿态
if defending: final = maxf(1.0, final * 0.5)
```

| 常数 | 值 | 作用 |
|---|---|---|
| `DAMAGE_SWING` | 0.10 | 伤害浮动 ±10% |
| `DAMAGE_FLOOR` | 0.10 | **保底**：至少打出原始伤害的 10%（防御堆满也打得动）|
| `DAMAGE_CAP` | 0.95 | **封顶**：最多打出 95%（防御为 0 也不会一击秒）|

### 为什么这么设计

- **减法**：防御是按点数抵消伤害，不是百分比。堆防御对低攻目标收益极大、对高攻目标收益有限 —— 这就是"破防"概念。
- **保底 10%**：没有保底时，防御 > 攻击就完全打不动，会出现「全员堆防御互相摸不动」的僵局。
- **封顶 95%**：没有封顶时，高攻对零防的伤害会无限膨胀，一击秒杀。
- **格挡放在保底之后**：格挡对「高频低伤」特别有效（每次都被吃掉固定值），但对「单次高伤」收益低 —— 这符合"格挡 = 抵消冲击"的直觉。

### 实算（100 级橙装量级：攻击 959、气血 973）

| 场景 | 对方防御 | 伤害 | 占攻击比 | 击杀所需 |
|---|---|---|---|---|
| 物理 | 320（只穿衣服）| 575 ~ 703（均 639）| 66.6% | **2 刀** |
| 物理 | 646（穿满四件）| 282 ~ 344（均 313）| 32.6% | **4 刀** |
| 法术（法伤 341）| 154 | 168 ~ 206（均 187）| 54.8% | 6 下 |
| 法术（法伤 341）| 445 | **34**（保底 10%）| 10.0% | 29 下 |

极端：

```
攻击 90  vs 防御 600           → 9.0    （保底，永远打得动）
攻击 5000 vs 防御 0            → 4719   （封顶，不秒杀）
攻击 900 防御 300 格挡 50       → 550
攻击 900 防御 300 防御姿态      → 300    （×0.5）
```

## 二、普攻

```gdscript
func roll_damage() -> float:
	return maxf(1.0, stats.damage)
```

**普攻伤害 = 攻击方的「伤害」属性**，无倍率、无随机（随机在 `take_damage()` 里做）。

`stats.damage` 的构成（见 `GameRoot.derived_stats()`）：

```
伤害 = 力量 × 0.75/0.7/0.8（三族不同）
     + 装备[攻击]（武器 / 项链 / 戒指）
     + 门派被动（damage_pct 走状态层）
     × (1 + 装备[物伤%]/100)
```

## 三、暴击

```gdscript
# 判定
Global.get_chance_success(0.10 + stats.crit_rate / 100 + status("crit_rate") / 100 + skill.crit_bonus)

# 倍率
func crit_multiplier() -> float:
	return 1.5 + status("crit_damage_bonus") / 100.0
```

| 项 | 值 |
|---|---|
| 基础暴击率 | **10%** |
| 装备暴击率 | 加在基础之上 |
| 基础暴击倍率 | **×1.5** |
| 暴击伤害词条 | 加在倍率上（+15% → ×1.65）|

**暴击在 `take_damage()` 之前结算**，所以封顶的基准是"暴击后的原始伤害"。

## 四、技能伤害

```gdscript
func skill_damage(skill, hit := 0) -> float:
	var raw := stats.damage                                    // 物理技
	if skill.damage_type == MAGIC: raw = stats.spell_damage    // 法术技
	var power := skill.power
	if skill.hit_power 有第 hit 段: power = skill.hit_power[hit]
	var base := skill.flat_damage if skill.fixed_damage else power * raw
	base = maxf(1.0, base)
	base *= 1.0 + (status("damage_pct") + status("damage_spell")) / 100.0
	base += status("spell_damage")
	return base
```

| 字段 | 含义 |
|---|---|
| `power` | 倍率（默认 2.2）|
| `fixed_damage` + `flat_damage` | 固定伤害，不随攻击力成长（缥缈剑指 / 药雾弥漫）|
| `hit_power[]` | 连击每段单独倍率（太虚神剑 3 段：`[0.4, 0.6, 0.8]`）|
| `hits` | 对同一目标结算几次 |
| `damage_type` | `PHYSICAL` 走「伤害 vs 防御」，`MAGIC` 走「法伤 vs 法防」|
| `crit_bonus` | 额外暴击率（0~1 小数）|

`skill_damage()` 之后同样走 `take_damage()` 的攻防差曲线。

## 五、群体衰减

`GameRoot` 里有两个常数，**目前没有接进战斗**（预留）：

```gdscript
const SKILL_SINGLE_POWER := 1.8
const SKILL_AOE_DECAY := 0.12
static func SKILL_AOE_DECAY_STEP(n: int) -> float:
	return maxf(0.3, 1.0 - SKILL_AOE_DECAY * float(maxi(1, n) - 1))
```

设计意图：单体技能倍率 ×1.8，群体技能每多一个目标衰减 12%，最低 70%。

**现状**：多目标技能每个目标都按原倍率结算，没有衰减。

## 六、速度与出手顺序

```gdscript
func turn_speed() -> float:
	return float(stats.speed) + randf_range(-4.0, 4.0)
```

| 项 | 说明 |
|---|---|
| 基础 | `stats.speed`（体质 0.1 + 耐力 0.1 + 敏捷 0.7 的总和 + 装备）|
| **乱敏** | **±4 点**随机，同速单位顺序不固定 |
| 缓存 | 每回合排序前 `roll_turn_speed()` 缓存一次，排序过程不变 |

**为什么必须缓存**：排序会反复调比较函数，如果里面每次取随机数，`a>b` 和 `b>a` 可能同时成立，引擎会报 `bad comparison function` 且结果未定义。

## 七、蓝耗与冷却

```gdscript
caster.spend_mana(skill.mana_cost)   // 起手扣蓝
caster.start_cooldown(skill)         // 起标记冷却
```

| 字段 | 说明 |
|---|---|
| `mana_cost` | 蓝耗，默认 6.0 |
| `cooldown` | 冷却**回合数**，默认 0（每回合可放）|
| 扣减时机 | 每回合开始 `tick_cooldowns()` |

## 八、状态（封印 / 禁法 / 治疗 / 增益 / 持续回血）

| 状态 | 触发字段 | 效果 |
|---|---|---|
| **封印** | `seal_chance` | 命中后目标下次行动跳过并消耗 |
| **禁法** | `silence_chance` + `silence_turns` | N 回合内不能放技能（可以普攻）|
| **治疗** | `heal_power` | 回复量 = 施法者 `healing × heal_power` |
| **持续回血** | `hot_turns` + `hot_power` | 每回合回 `healing × hot_power` |
| **增益** | `buff_stat` + `buff_value` + `buff_per_level` + `buff_turns` | 见 `BattleUnit` 的 `BUFF_STATS` |

状态存在 `BattleUnit.statuses` 里，同种状态会**合并**（数值相加、回合取长）。

## 九、目前还没接的数值

这些属性在装备/门派里已经能产出，但战斗里**还没有消费**：

| 属性 | 现状 |
|---|---|
| `dodge`（躲避）| 只有面板显示，未做命中判定 |
| `seal_hit`（封印命中）| 只有面板显示，封印仍是 `seal_chance` 固定概率 |
| `seal_resist`（抵抗封印）| 只有面板显示 |
| `crit_resist`（抗暴击）| 只有面板显示 |
| `crit_damage_resist`（爆伤减免）| 只有面板显示 |
| `healing`（治疗量）| 接在 `heal_power` 和治疗上 ✓ |
| `block_value`（格挡值）| 接在 `take_damage()` 第 ④ 步 ✓ |
| `physical_pct` / `spell_pct` | 接在 `derived_stats()` 的乘算里 ✓ |
| `health_pct` / `defense_pct` / `speed_pct` | 接在 `derived_stats()` 的乘算里 ✓ |

> 想把躲避/抗暴/封印命中接进战斗，改 `BattleUnit.roll_crit()` 与 `Battle._apply_skill_statuses()` 即可。
