# 装备体系文档

> 本文档是装备体系的唯一说明源（原 `装备命名表.csv` 已合并进来并删除）。

## 一、体系概览

| 维度 | 内容 |
|---|---|
| 等级 | 0 ~ 150，每 10 级一套，共 **16 套** |
| 格位 | **13 个**：6 种武器（剑/刀/扇/枪/杖/爪）+ 7 种防具首饰（衣服/腰带/鞋子/头盔/项链/戒指/耳饰）|
| 品质 | **5 档**：白 / 蓝 / 紫 / 粉 / 橙 |
| 总量 | 16 × 13 × 5 = **1040 件** |

## 二、品质规则

| 品质 | 值 | 价格倍率 | 词条 | 描边色 |
|---|---|---|---|---|
| **白** | 0 | 1.0x | 固定主属性 2 项 | 无描边，深灰底 |
| **蓝** | 1 | 1.8x | +2 条双加基础属性 | 蓝 #008EBD |
| **紫** | 2 | 3.2x | +1 条稀有词条 | 紫 #7A40B5 |
| **粉** | 3 | 5.5x | +2 条稀有词条 | 粉 #E86BA8 |
| **橙** | 4 | 9.0x | +3 条稀有词条 | 橙 #FA9E3B |

**词条是叠加的**：橙品质 = 固定主属性 2 项 + 双加 2 项 + 稀有 **3** 条。

## 四、数值体系

### 4.1 品质分配（方案 B）

每件装备的数值都落在「该等级段的区间」里，按品质均分：

```
白 = 区间最低    蓝 = 25%    紫 = 50%    粉 = 75%    橙 = 区间最高
```

### 4.2 各部位主属性

| 部位 | 主属性 | 150 级区间（白~橙）|
|---|---|---|
| 武器 | 物伤 + 法伤 | 638 ~ 871 |
| 项链 | 物伤 + 法伤（灵力当伤害）| 185 ~ 252 |
| 衣服 | 防御 | 235 ~ 320 |
| 腰带 | 防御 + 气血 | 80~109 / 310~423 |
| 头盔 | 防御 + 魔法 | 79~108 / 118~153 |
| 鞋子 | 防御 + 敏捷 | 79~108 / 50~67 |
| 戒指 | 物伤 + 防御 | 75 ~ 113 |
| 耳饰 | 法伤 + 法防 | 75 ~ 113 |

### 4.3 各部位公式

设 `L` = 装备等级下限：

| 部位 | 属性 | 公式 |
|---|---|---|
| 武器 | 总伤 | `160+(L-50)×3 + (185+(L-50)×3.5)/3` ~ `218+(L-50)×4.1 + (252+(L-50)×4.77)/3` |
| 项链 | 灵力 | `65+(L-50)×1.2` ~ `88+(L-50)×1.64` |
| 衣服 | 防御 | `235+(L-150)×1.5` ~ `320+(L-150)×2.05` |
| 腰带 | 防御 | `30+(L-50)×0.5` ~ `40+(L-50)×0.69` |
| 腰带 | 气血 | `110+(L-50)×2.0` ~ `149+(L-50)×2.74` |
| 头盔 | 防御 | `30+(L-50)×0.49` ~ `39+(L-50)×0.69` |
| 头盔 | 魔法 | `55+(L-50)×0.98×0.77` ~ `55+(L-50)×0.98` |
| 鞋子 | 防御 | 同头盔防御 |
| 鞋子 | 敏捷 | `20+(L-50)×0.3` ~ `27+(L-50)×0.4` |
| 戒指 | 物伤 / 防御 | `(12+(L-60)×0.2)×2.5` ~ `(18+(L-60)×0.3)×2.5` |
| 耳饰 | 法伤 / 法防 | 同戒指 |

> **戒指/耳饰的 ×2.5**：原表数值相对其他部位偏低（150 级只有 30~45），
> 乘 2.5 后 75~113，略高于头盔（108），饰品终于有了分量。
>
> **鞋子用敏捷不用速度**：1 点敏捷 = 0.7 速度 + 1.0 躲避 + 0.12 暴击率 + 0.08 抗封，
> 收益是直接加速度的 2~3 倍。
