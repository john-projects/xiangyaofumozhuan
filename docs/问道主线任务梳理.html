一、先弄清楚：《问道》的“主线”是什么

《问道》并没有一条从 1 级贯穿到满级的单一主线，而是由若干条按真身等级解锁的剧情任务串成，分成三块：

  1. 正传剧情（十部，共 82 章）：妖魔道 → 仙魔录 → 伏魔记 → 幻仙劫 → 鲲鹏变 → 地藏王传 → 后羿射日 → 夸父逐日 → 精卫填海 → 天狗吞月。
  2. 境界主线（4 个阶段）：100 级百级拜师 → 110 级“引路人”（凝结元婴/血婴）→ 元婴 130 级“仙道难”（飞升）→ 150 级“南天门试炼”（飞仙）。
  3. 番外剧情：西域迷情（100 级以上，4 章）等独立故事。

剧情任务的共同规则：

  • 一次性任务，领取后不会消失，完成后无法再次完成；
  • 多数要求单人领取，可以组队完成，但只有队长能推进并完成任务；
  • 战斗难度普遍偏高，越往后越建议满编组队；
  • 剧情奖励的经验多数不受双倍、三倍、全局双倍影响，并按自身等级削减；
  • 关键章节会给予剧情称谓、对应等级的改 3/改 5 蓝（金）装备、首饰、超级女娲石等。

二、故事背景

封神杀劫千年之后，妖族与魔族再度凝聚力量，图谋中州。玩家作为五大门派（金、木、水、火、土）的修道弟子，从揽仙镇一桩药材失窃的小事查起，一路揭开梅山七妖、兽神、镜中仙、北冥鲲鹏的连环阴谋；随后在上古神器与神祇的指引下“穿越”回上古，亲历目连救母、后羿射日、夸父逐日、精卫填海、天狗吞月的传说，最终在天狗与天庭的冲突中为灵兽族讨回公道。

四、逐部详解

说明：前五部（妖魔道—鲲鹏变）按官方逐章标注的等级列示；穿越篇（地藏王传—天狗吞月）每章等级依次 +1，表中等级以官方标注的首章、末章为准（如地藏王传 116 起、125 止，天狗吞月 156 起、165 止）。

1. 妖魔道（20—80 级，7 章）

定位：全剧情的开端。从揽仙镇药材失窃查起，牵出假药方、五龙窟恶龙、幽冥涧逃犯，最终在绝人阵与恶灵鬼王决战。这一部同时承担“教学”职能：教你认 NPC、跑地图、组队打剧情战斗。

2. 仙魔录（65—92 级，10 章）

定位：整个中州篇的主干，也是称谓党最熟悉的一部。梅山修炼成精的七只妖怪成立“七尸十三堂”，欲颠覆天庭；玩家在众仙指点下周旋于各大妖魔之间，最终直捣黄龙，消灭七妖之首千年白猿精“袁洪”。仙魔录 65 级即可开启，与妖魔道后两章（70、80 级）在等级上重叠，两条线可按等级穿插完成。

五、境界主线：元婴、飞升与飞仙

这条线不叫“剧情任务”，但决定了你能不能继续升级、能不能接后续正传，实质上是另一条主线。

南天门试炼（飞仙）150南天门试炼南华真人（无名小镇 103,51）依次击败雷神、花神、龙神、炎神、山神，得“南天门试炼金丹”，完成飞仙

注意：引路人任务领取后无法再找南华真人更换元婴/血婴；仙道难的所有剧情触发都必须以元婴/血婴形态进行；飞升后每升 1 级得 1 点修道点，可在天墉城鬼道子处分配仙道点/魔道点。

附：宠物飞升（宠物 110 级、亲密度 30000，东海渔村·灵兽异人）：让宠物突破 125 级上限，抗性上限与成长提升，与人物飞升线并行。

六、番外与“容易混进主线”的任务

  • 西域迷情（1.59 版本，真身 ≥100）：四章“中州异客 → 救死扶伤 → 王位之争 → 真相大白”。西域古城瘟疫、两位王子争位，幕后是千年前妖王蜃精。独立剧情，不属于正传序号。
  • 天降大任（30 级以上，天墉城青木道人）：传送到练功区完成守护神试炼，给经验、道行、武学，本质是练级任务。
  • 修行 / 仙人指路（50—100 级，东海渔村柳如尘）：3 人以上组队的循环修行，胜 5 位神仙领经验、道行、宠物经验与武学。
  • 天劫 / 地劫（134 级起，需先完成飞升）：天劫共十劫，每通过一劫提升单项相性点上限、突破当前等级上限，并获得“一劫散仙”等称号；未完成当前劫难时不获得经验。
  • 300 连环任务（50 级以上，问道活动大使）：每周一次的跑环，300 环封顶，可抽神兽精魄等大奖。
  • 亲子任务、功德任务、浮生传记：独立玩法或角色支线，不推进正传。

七、跑主线的实用建议

  1. 记住几个卡点：65（仙魔录开启）、92（仙魔录完结）、101（伏魔记）、110（引路人）、116（地藏王传入场）、126、134（天劫第一劫）、136、146、156。每到卡点先确认前置是否做完，否则会“等级够了却接不到任务”；134 级起每升一级都要先渡一劫，未渡劫时不获得经验。
  2. 先做 100 级拜师：不做百级拜师，110 级接不到引路人；不凝婴，真身卡在 125 级，126 级后的穿越篇全部无法开启。
  3. 组队配置：剧情战斗普遍是“1 主怪 + 多小怪”或连续多场，建议 5 人满编，带木系（疗伤/复活）、水系（障碍控制）、高防体宠；后期章节主怪速度、伤害都高，先清小怪再集火主怪。
  4. 别浪费双倍：剧情经验大多不吃双倍/三倍/全局双倍，双倍时间留给刷道或日常。
  5. 称谓是隐藏奖励：仙魔录十章的称谓链（江湖游侠 → 无量天尊）是很多老玩家的收藏目标，战斗胜利时队长和自己都没死还能多拿 1 点好心值。
  6. 奖励随等级削减：穿越篇明确“三倍、双倍、全局双无效，均按自身等级进行削减”，卡级做剧情并不划算，按等级推进即可。

八、版本与平台说明

  • 端游：光宇游戏运营，2006 年公测的 2D 回合制修真网游，五系（金木水火土）十角色，本文即以此为准。
  • 手游：《问道》手游由雷霆游戏发行，主线按“章节”推进，剧情结构与端游不完全一致（例如早期同样有妖魔道、仙魔录、伏魔记的等级段，但章节划分与任务名有差异），不能直接套用本文的章节表。
  • 版本：官方资料页的等级、奖励多为“最初上线规则”，历次版本可能调整过战斗难度、奖励数值与个别任务名；本文标注的等级段以官方页面为准，若游戏内显示不同，以游戏内为准。
