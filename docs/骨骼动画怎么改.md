# 怎么改骨骼角色的关节与动画

## 一、先分清两件事

| 要改什么 | 在哪改 | 会不会被覆盖 |
|---|---|---|
| **关节位置**（肩在哪、肘在哪）| Godot 编辑器，选节点改 `position` | ✓ 保存就生效 |
| **动画**（走路怎么摆、攻击怎么挥）| `scenes/characters/rig_player.gd` 里的数字 | ✗ 代码里改，编辑器看不到 |
| **部件位置**（袖子放哪）| 编辑器，选 `s_xxx` 的 Sprite2D 改 `position` | ✓ |

**关键**：动画是**代码运行时生成**的，所以在编辑器的 AnimationPlayer 面板里是**空的**。
要看效果只能按 **F6** 运行。

---

## 二、改关节位置

1. 打开 `scenes/characters/rig_陆孤鸣_v4.tscn`
2. 场景树里选 `关节 → hip → spine → chest → arm_l`
3. 检查器里改 **Transform → Position**

```
关节层级：
hip        (0, -638)     胯
└ spine    (0, -80)      腰      ← 相对 hip
  └ chest  (0, -70)      胸      ← 相对 spine
    ├ neck (0, -92)      脖子
    │ └ head (0, -324)   头
    ├ arm_l  (-100, -40) 左肩    ← 相对 chest
    │ └ fore_l (0, 150)  左肘    ← 相对 arm_l
    │   └ hand_l (0, 110) 左腕   ← 相对 fore_l
    └ arm_r / fore_r / hand_r
```

⚠ **所有 `position` 都是相对父节点的**，不是绝对坐标。

改完保存 → 按 F6 看效果。

## 三、改动画

打开 `scenes/characters/rig_player.gd`，四条动画在 `_ready()` 里：

```gdscript
_make("idle", 2.0, true, {
	"关节/hip/spine:rotation": [Vector2(0.0, 0.0), Vector2(1.0, 0.012), Vector2(2.0, 0.0)],
	...
})
```

### 三个参数

```gdscript
_make( 名字 , 时长秒 , 是否循环 , { 轨道 } )
```

### 轨道的写法

```gdscript
"节点路径:属性": [ Vector2(时间, 值), Vector2(时间, 值), ... ]
```

| 部分 | 说明 |
|---|---|
| 节点路径 | 从根算起，`关节/hip/spine/chest/arm_r`（**骨头名**，不是贴图名）|
| 属性 | `rotation`（弧度）或 `position`（Vector2）|
| Vector2(时间, 值) | 第 0 个分量 = 时间（秒），第 1 个分量 = 值 |

### 弧度换算

```
弧度 = 角度 × π / 180
 5° ≈ 0.087
10° ≈ 0.175
15° ≈ 0.262
20° ≈ 0.349
30° ≈ 0.524
45° ≈ 0.785
```

**正数 = 顺时针**（Godot 的 y 轴朝下）。

### 常用改法

**① 动作幅度太小** → 把数值调大

```gdscript
# 攻击前挥 0.35rad（20°）不够狠
"关节/hip/spine/chest/arm_r:rotation": [Vector2(0.0,-0.05), Vector2(0.12,-0.9), Vector2(0.28, 0.35), Vector2(0.55,-0.05)]
#                                                                                                    ↑ 改成 0.6
```

**② 动作太慢** → 改第二个参数（时长）

```gdscript
_make("attack", 0.55, false, {...})   # 0.55 秒
                 ↑ 改成 0.35 更快、0.8 更慢
```

**③ 想加一个关节参与** → 在字典里加一行

```gdscript
_make("cast", 0.8, false, {
	"关节/hip/spine/chest/arm_l:rotation": [...],
	+ "关节/hip/spine/chest/arm_l/fore_l:rotation": [Vector2(0.0,0.0), Vector2(0.3,-0.4), Vector2(0.8,0.0)],
})
```

**④ 走路只有上下起伏、没有腿** → v4 没有腿骨。想要腿得先加两根 `leg_l` / `leg_r` 骨头
（挂 `hip` 下），再在轨道里写 `:position`。

## 四、⚠ 关于 `position` 轨道

**`position` 轨道写的是完整坐标，不是增量。**

```gdscript
// ✗ 这样会让角色瞬移到 (0, -20)
"关节/hip/leg_l:position": [Vector2(0.0, -20.0), ...]

// ✓ 正确：先读当前基准值，再在它基础上加减
var bl := leg_l.position                       # (0, 0)
"关节/hip/leg_l:position": [bl, Vector2(bl.x, bl.y - 26), bl]
```

`walk` 里已经这么做了（`var bl := leg_l.position`），所以你在编辑器里挪腿，动画会跟着走。

**但 `rotation` 轨道没这个问题** —— 0 就是原姿势。

## 五、怎么快速试

1. 改完 `rig_player.gd` 保存
2. 打开 `rig_陆孤鸣_v4.tscn`
3. **F6** 运行
4. 按：

| 键 | 动画 |
|---|---|
| 1 | idle 待机 |
| 2 | walk 走路 |
| 3 | attack 攻击 |
| 4 | cast 施法 |
| R | 静止（所有关节归零，检查对齐）|

左上角会显示当前播的是哪条。

## 六、想在编辑器里可视化调动画？

`AnimationPlayer` 面板现在是空的，因为动画是代码生成的。

**想要可视化编辑**有两条路：

**① 把动画烘焙进场景**（我可以帮你做）
在编辑器里打开 AnimationPlayer 面板，能看到四条动画、能拖时间轴、能加关键帧。
代价：不能再用代码改，两边只能选一个。

**② 保持代码，用 F6 快速预览**
改一个数字 → F6 → 看 → 再改。循环一次 5 秒左右。

## 七、常见问题

**Q：改完没效果？**
A：忘了保存 `.gd`，或者运行的场景不是 v4。

**Q：角色整个飞走/消失？**
A：`position` 轨道写错了完整坐标（见第四节）。

**Q：报 `Invalid access to property 'position' on a null instance`？**
A：轨道里的骨头在场景里不存在。v4 没有 `leg_l`/`leg_r`，walk 里已经做了判空。

**Q：动画不循环？**
A：第三个参数 `true` 才是循环。`attack`/`cast` 是 `false`，播完自动回 idle。
