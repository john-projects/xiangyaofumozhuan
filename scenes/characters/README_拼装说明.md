# 角色 2D 拼装场景 · 使用说明

## 这是什么

`rig_<角色名>.tscn` 是一个**已经摆好初始位置**的角色拼装场景。所有拆件都已经作为
`Sprite2D` 节点放进场景树，你在 Godot 编辑器里**直接拖 / 转 / 缩放**就能调位置，
不需要改任何代码。

目前只做了 **陆孤鸣**（`rig_陆孤鸣.tscn`）。

## 怎么用

1. 在 Godot 里双击 `scenes/characters/rig_陆孤鸣.tscn` 打开
2. 左边场景树里选中某个部件（节点名是中文，如 `body_衣服`、`head_头`）
3. 上方工具栏选 **移动（W）/ 旋转（E）/ 缩放（R）**，在 2D 视图里拖
4. `Ctrl+S` 保存

## 场景结构

```
UnitRig_陆孤鸣            ← 根节点，原点 = 脚底
└ 关节                    ← 所有骨骼节点挂在这里
   └ hip                  ← 胯（y = -130）
      ├ leg_l / leg_r     ← 左/右脚（相对胯 +130，即回到脚底 y = 0）
      │   └ boot_左靴 / boot_右靴
      └ spine             ← 腰（-60，累计 y = -190）
         ├ skirt_下摆
         └ chest          ← 胸（-90，累计 y = -280）
            ├ body_衣服
            ├ neck        ← 脖子（-100，累计 y = -380）
            │   └ head    ← 头（-70，累计 y = -450）
            │       └ head_头
            ├ arm_l       ← 左肩（x -72, y -70，累计 y = -350）
            │   └ fore_l  ← 左肘（+100，累计 y = -250）
            │       └ arm_l_lo_左前臂
            └ arm_r
                └ fore_r
                    └ arm_r_lo_右前臂
```

**关节的 y 都是「相对父关节」**，所以 `leg_l` 的 `position.y = +130` 是对的
（跨在 -130，脚回到 0）。

## 每个 Sprite2D 的参数含义

| 参数 | 说明 |
|---|---|
| `centered = false` | 用**左上角**定位，`position` 就是左上角坐标，比中心定位好调 |
| `position` | 相对**所在关节**的偏移 |
| `scale` | 部件缩放（各部件原始分辨率不同，所以每个的缩放不一样） |
| `z_index` | 层级：下摆 10 → 衣服 20 → 袖子 15/16 → 头 30；靴子 5 |

## 各部件当前参数

| 节点 | 贴图 | 缩放 | z | 挂在哪 |
|---|---|---|---|---|
| `skirt_下摆` | skirt_front | 0.85 | 10 | spine |
| `body_衣服` | robe_front | 0.78 | 20 | chest |
| `head_头` | face_1 | 1.50 | 30 | head |
| `arm_l_up` → `arm_l_up_左广袖` | sleeve_a | 0.90 | 15 | arm_l |
| `arm_r_up_右广袖` | sleeve_a | 0.90 | 15 | arm_r |
| `arm_l_lo_左前臂` | forearm_a | 0.85 | 16 | fore_l |
| `arm_r_lo_右前臂` | forearm_b | 0.85 | 16 | fore_r |
| `boot_左靴` | boot_1 | 0.90 | 5 | leg_l |
| `boot_右靴` | boot_2 | 0.90 | 5 | leg_r |

> 左右**广袖用的是同一张** `sleeve_a`（设计图里只有一侧），需要右袖镜像的话
> 把 `arm_r_up` 下的 Sprite2D 的 `flip_h` 打开即可。

## 还能用但没放进去的部件

`parts/陆孤鸣/` 里一共 32 张，这次只用了 9 张。剩下可替换/补充的：

| 类别 | 文件 | 用途 |
|---|---|---|
| 表情 | `face_1` ~ `face_9` | 换表情（直接改 `head_头` 的 texture）|
| 发型 | `hair_front` / `hair_back` / `hairpin` | 换发型、加发簪 |
| 手 | `hand_1` ~ `hand_5` | 换手部姿势 |
| 袖子 | `sleeve_a/b/c` | 三种角度 |
| 前臂 | `forearm_a/b` | 左右 |
| 靴子 | `boot_1` ~ `boot_5` | 五个角度 |
| 衣服背面 | `robe_back` | 背面朝向时用 |
| 下摆背面 | `skirt_back` | 同上 |
| 光头 | `head_bald` | 配发型用 |

## 缺的东西（需要美术补）

| 缺件 | 影响 | 建议 |
|---|---|---|
| **大腿/腿** | 裙摆一掀就露空 | 补一条裤/袜拆件；或用纯色块占位 |
| **脖子** | 转头时露缝 | Q 版影响很小，可用领口盖住 |
| **武器** | 手上没东西 | 可以直接拿 `assets/sprites/equipment/` 的武器图标 |
| **飘带/衣摆分片** | 下摆是一整片，飘不起来 | 想让它飘得切成 2~3 片 |
