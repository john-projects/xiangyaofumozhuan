# 游戏总流程（scenes/main/）

`main.tscn` 是**唯一主场景**（`project.godot` 的 `run/main_scene` 指向它）。

## 流程

```
主菜单 TitleScreen          ← 支持纯键盘：↑↓ / W S 选择，Enter / 空格 / E 确认（Esc 不做事）
   ├── 新的征程   → **直接开局**：队长取 GameRoot.default_leader（留空则用 DEFAULT_LEADER，
   │                 当前指向 resources/units/players/stats_player_well_rounded.tres）
   ├── 继续游戏   → 恒为置灰（没有存档系统），不进键盘焦点环
   └── 退出游戏
直接开局 → 世界地图 WorldMap（起点：建邺城，可走动探索）
   ├── 走到 NPC 旁按 E 交谈 → 选目的地 → 传送到另一张图（双向）
   ├── 找「队友」NPC 招募队友（进"团队"名册，默认不限人数；最多 5 人"上阵"）
   │   └── Esc →「队伍管理」里切换上阵/下阵、把人移出团队（敌人数量跟着**上阵人数**变）
   ├── 找「商人」NPC 买装备（卖现有全部 26 件：头盔/武器/腰带/项链/衣服/鞋子；背包 120 格）
   │   ├── 交易窗口贴最左边（顶部只有居中的名字）、背包贴最右边；货架总共 6×20 = 120 格、一屏 6×10（84px）
   │   └── 点货架格子 = 买（先弹确认框，含价格）；**点背包格子 = 卖**（同一个确认框，卖价 = 原价 × 75%）
   ├── 角色头顶显示名字；**上阵队友会以小人形式跟在队长身后**（沿轨迹跟随，上阵/下阵立刻增减）
   ├── 按 B（或 Esc →「背包」）单独开背包：右下角窗口，标题「背包 n/120」+ 形象与装备栏（96px）+ 信息行（左金币/右提示）+ 8×8 格（68px）
   │   └── **没在交易时点背包格子 = 给当前展示的角色穿上**（六个装备栏：头盔/武器/腰带 · 项链/衣服/鞋子），点已穿的栏位 = 脱下
   │       └── ◀ / ▶ 换人：**每个进团队的角色各有一套装备**，切到谁就显示/穿谁的
   ├── 按 C（或 Esc →「角色属性」）开角色属性面板：**贴屏幕左下角、和背包同宽 662**，
   │     **只开属性面板、不连带背包**；开着属性面板时按 B 可以单独把右边背包打开（两个都能点）；
   │     上半部分和背包**同款**（◀ 形象 240×308 + 名字牌 ▶ + 左右各 3 个 96px 装备栏，点已穿的直接脱下）；
   │     形象/装备栏下方有「属性 / 门派技能 / 其他技能」三个页签：属性页是下面那张两列表格；门派技能页是技能表（名称/等级/类型/目标/消耗，点一行看描述并升级）；其他技能页是 UnitStats.skills 里的角色技能；
   │     面板高度按属性页算一次（切页签不变），技能太多时下半部分可下滑；位置/间距见 world/README
   │     （◀ / ▶ 换人，两边同步；加成那行明确写「暂未计入战斗」）
   ├── 进入战斗（右下按钮，或 Esc 操作菜单）→ 回合制战斗 Battle（scenes/battle）
   └── 返回主菜单（Esc 操作菜单）
战斗结束 → 结算 → 回到同一张地图的**原位置**（胜利：发金币 + 经验、记录已通关；失败：可再挑战）
```

> **键盘约定**（主菜单 / 世界地图 / 三个浮层都一样）：`↑↓`+`Enter`/`空格` 走 Godot 内置的
> `ui_*` 与 GUI 焦点系统；`W S` + `E` 由各屏幕的 `_unhandled_input` 调 `Global` 里的
> 焦点工具补上（`can_focus` / `collect_focusable` / `step_focus` / `activate_focused` /
> `is_interact_event`）。屏幕一出现就必须 `grab_focus()` 一个按钮，否则方向键"没人可动"。

> **竞技场（「经典模式」）已经整体移除**：主菜单只剩「新的征程 / 继续游戏 / 退出游戏」，
> 与它配套的选人界面、商店/升级面板、武器（ItemWeapon）、实时战斗单位、卡牌与波次资源
> 也一起删掉了。现在唯一的玩法线就是「地图 → 回合制战斗」。

地图玩法（走动/相机/NPC/传送）细节见 **[../world/README.md](../world/README.md)**。

## 地图串联

```
建邺城 jianyecheng ⇄ 东海湾 donghaiwan ⇄ 傲来国 aolaiguo ⇄ 花果山 huaguoshan（终点）
```

双向传送由各图 NPC 的 `destinations` 互相指向实现（不是写死在代码里的链条）：

| 地图 | NPC → 目的地 |
|---|---|
| 建邺城 | 船夫 → 东海湾 |
| 东海湾 | 船夫 → 建邺城；向导 → 傲来国 |
| 傲来国 | 向导 → 东海湾；猎人 → 花果山 |
| 花果山 | 看山猴 → 傲来国 |

### 加一张新地图（比如已经躺在 `assets/map/` 里的狮驼岭）

1. 复制 `resources/maps/map_huaguoshan.tres` → 改名 `map_shituoling.tres`；
2. 改 `id` / `display_name` / `texture`，配好 `npcs`（`destinations` 里双向互指）；
3. 把新的 `.tres` 拖进 `main.tscn` 上 `Main` 节点的 **Maps** 数组；
4. （可选）想给这张图摆装饰/加碰撞，就在 `scenes/world/maps/` 下"新建继承场景"（继承 `world_map.tscn`），
   保存成 `world_shituoling.tscn`，再填进这个 `.tres` 的 `scene` 字段。详见 [../world/README.md](../world/README.md)。

## 场景结构

```
Main (Node)  [main.gd = GameRoot]
├── WorldRoot       (Node2D)      —— 世界类屏幕：WorldMap / Battle
├── UIRoot          (CanvasLayer) —— UI 类屏幕：TitleScreen
└── TransitionLayer (CanvasLayer, layer=200)
	└── Fade        (ColorRect)   —— 黑幕淡入淡出（过渡期间挡输入）
```

> 注意：地图现在是 **Node2D 世界**（要相机跟随玩家），所以挂 `WorldRoot` 而不是 `UIRoot`。

## 数值规则（都在 `main.gd` 顶部可调）

| 参数 | 默认 | 说明 |
|---|---|---|
| 起点地图 | `maps[0]`（或 `start_map_id`） | 建邺城 |
| 敌人池 | 地图的 `enemy_pool`，留空则用 `GameRoot.enemy_pool` | 5 个敌人 `.tres` 挂在 `main.tscn` |
| 敌人数量 | **上阵人数 ±1**（随机，钳进 1~5） | 只看 `deployed`（上阵名单），团队里坐板凳的人不算；上限 = `MAX_ENEMY_COUNT` / Battle 的 5 个敌方站位 |
| 敌人强度 | `enemy_scale_per_map = 0.15` | 每图血量/伤害 +15%，用 `duplicate()` 生成副本，不污染 `.tres` |
| 通关奖励 | `coin_reward_per_map(40) × 难度` | 累加进 `Global.coins` |
| 通关经验 | `exp_reward_per_map(120) × 难度 + exp_per_enemy(20) × 敌人数量` | 第 1 图 2 敌 = 160、第 4 图 5 敌 = 580；**发给这一场上阵的每个队员**（`add_exp()` 按人处理连升与溢出，板凳不上场不涨） |
| 等级 / 满级 | 每个角色各自 1 ~ `MAX_LEVEL = 100`（`Global.level_by_character` / `exp_by_character`） | 曲线 `need(L) = 60 + 20L + 0.42L²`，1→100 累计 **242,852** 经验；见下面「等级与经验」 |
| 基础属性 | `ATTR_PER_LEVEL = 1` / `ATTR_FREE_PER_LEVEL = 5` | 每升 1 级：五项基础属性各 +1，另给 5 点自由属性点（自己加到任意项）；见下面「基础属性与派生属性」 |
| 种族系数 | `ATTR_TABLE`（种族 → 基础属性 → 派生属性系数） | 人族均衡、仙族防高法强、魔族血多物理强；`_make_player_team()` 用 `derived_stats()` 写进战斗副本 |
| 种族 | `UnitStats.race`（`HUMAN/DEMON/IMMORTAL`，默认人族） | 陆孤鸣、燕如意 = 人族；行修、霓衣 = 仙族；厉狂澜、夜魑 = 魔族；敌人不读这个字段 |
| 门派 | `Global.SECTS`（5 个）+ `Global.sect_by_character`（角色键 → 门派 id） | 默认无门派；种族限制见 [../world/README.md](../world/README.md) 的「门派（拜师）」；一个角色只能拜一个门派、不能改投 |
| 门派技能 | `Global.SECT_SKILLS`（每门 2 被动 + 3 主动）+ `Global.sect_skill_levels_by_character`（角色键 → `{技能 id: 等级}`） | 拜入即学会全部 5 个技能（**各 1 级**）；**每个技能等级独立**，在属性面板「技能」页花**经验 + 金币**升（`upgrade_sect_skill()`），封顶 100，**不再随人物升级自动涨**；被动按各自等级加成，主动暂未接战斗。花费曲线见 world/README 的「技能升级」 |
| 初始金币 | `starting_coins = 500` | 新游戏时重置（等级/经验也重置回 1 级 0） |
| 背包 | `BAG_SLOTS = 120`（8 列 × 15 行，一屏 8×8） | 商人买入的落点（**卖出也从这里扣**）；背包面板（`B` 键）是右下角窗口，画满 120 格、一屏 64 格，其余靠滚动；交易时背包贴最右、商人贴最左，背包可点着卖；⚠ 装备属性目前只展示、战斗不读，见 [../world/README.md](../world/README.md) |
| 玩家站位记忆 | `_map_positions` | 打完战斗回地图时回到原位置（`WorldMap.spawn_override`） |

## 等级与经验（满级 100）

**曲线**：`need(L) = round(60 + 20×L + 0.42×L²)`（`L` = 当前等级 1..99；100 级不再需要经验）。
三个系数是唯一旋钮（`main.gd` 顶部的 `EXP_BASE / EXP_LINEAR / EXP_QUAD`）：底数管"前几级别太跳"，
线性项管中期手感，二次项管后期坡度。

**节奏表**（每级所需 / 本段合计 / 按该阶段常刷的图算的大约场次）：

| 等级段 | 每级所需 | 本段合计 | 常刷地图（3 敌）经验/场 | 约几场升 1 级 |
|---|---|---|---|---|
| 1–10 | 80 → 302 | 1,863 | 第 1 图 180 | 0.5 ~ 1.7 |
| 11–20 | 331 → 628 | 4,744 | 第 2 图 240 | 1.4 ~ 2.6 |
| 21–30 | 665 → 1,038 | 8,465 | 第 2 图 240 | 2.8 ~ 4.3 |
| 31–40 | 1,084 → 1,532 | 13,028 | 第 3 图 360 | 3.0 ~ 4.3 |
| 41–50 | 1,586 → 2,110 | 18,431 | 第 3 图 360 | 4.4 ~ 5.9 |
| 51–60 | 2,172 → 2,772 | 24,673 | 第 4 图 540 | 4.0 ~ 5.1 |
| 61–70 | 2,843 → 3,518 | 31,754 | 第 4 图 540 | 5.3 ~ 6.5 |
| 71–80 | 3,597 → 4,348 | 39,675 | 第 4 图 540 | 6.7 ~ 8.1 |
| 81–90 | 4,436 → 5,262 | 48,438 | 第 4 图 540 | 8.2 ~ 9.7 |
| 91–99 | 5,358 → 6,156 | 51,781 | 第 4 图 540 | 9.9 ~ 11.4 |

**1→100 累计 242,852 经验**，按上表的图打 ≈ **500~650 场**；如果只刷第 4 张图（540/场），从 1 级到满级约 450 场。
前 10 级一场就能升 1~2 级（给正反馈），90 级以后一级要十场左右（终局目标）。

**升级怎么算**（`GameRoot.add_exp(character, amount)`，唯一入口）：
- **按人算**：战斗胜利时遍历 `deployed`，给**每个上阵队员**各发一份同样的经验（`_on_battle_ended()`）；
  没上阵的板凳不涨 —— 等级/经验是角色自己的进度（`GameRoot.level_of()` / `exp_of()`）；
- **1→9 级自动升级**（`AUTO_LEVEL_LIMIT = 10`）：一场经验顶好几级时用 `while` 连升，溢出的留到下一级；
- **10 级起不再自动升级**：经验一直攒（封顶 `EXP_CAP = 100 亿`），玩家在属性面板**经验条右边的「升级」**按钮
  点一次才扣掉这一级需要的经验、升一级（`GameRoot.upgrade_level()`，唯一手动升级入口），
  成功后顶部弹一条「XX 升到 Lv.N（获得 5 点自由属性）」；
  按钮在经验不够/满级时置灰，悬停显示原因；
- **满级后经验照样攒**（封顶 100 亿）—— 升门派技能还要花它，所以不清零；只是不能再升级
  （面板上经验行显示「N 经验（已满级，可用于升技能）」，「升级」按钮置灰）；
- **结算文案是多条**：第 1 行「地图：战斗胜利！」、第 2 行「获得 N 金币 · 上阵每人经验 +M」，
  之后每个**自动升级了的队员**各一行「XX 升到 Lv.N（获得 K 点自由属性）」——
  地图用 `WorldMap.show_toast()` 按 `\n` 拆成多条弹窗逐条显示（10 级后不再有升级行，经验只累计）。

**属性成长**：升级不再乘全局百分比，而是发**基础属性点**，见下一节。

**调参**：整体调快/调慢改三个系数即可（比如 1→100 想压到 ~15 万经验，`EXP_QUAD` 降到 0.25 左右）；
经验获取太多/太少改 `exp_reward_per_map / exp_per_enemy`。

## 基础属性与派生属性

五项基础属性：**体质 / 魔力 / 力量 / 耐力 / 敏捷**（`GameRoot.ATTR_KEYS`）。

- `1 级底数`：五项**各有 11 点**（`ATTR_BASE`），否则 1 级角色五项全是 0、属性面板看起来像坏了；
- `每级成长`：升 1 级 → 五项**各 +1**（自动），再给 **5 点自由属性点**（玩家自己分配）；
- `总点数` = `ATTR_BASE(11) + (等级-1) × 1 + 自由分配的点`（`GameRoot.attribute_points()`；自动成长不落盘，按等级现算）；
- `自由点` = `(等级-1) × 5 − 已分配`（`free_attribute_points()`），在属性面板（`C`）里点「＋」分配；
- `分配`只走 `GameRoot.allocate_attr(character, index)`（唯一写入点，存 `Global.attr_alloc_by_character`）。

**派生属性**（`GameRoot.derived_stats()` = `.tres` 基础值 + Σ 点数 × 系数，系数表 `GameRoot.ATTR_TABLE`）：

| 基础属性 | 人族 | 仙族 | 魔族 | 主加 |
|---|---|---|---|---|
| 体质 | 气血 +5、法伤 +0.3、速度 +0.1 | 气血 +4.5、法伤 +0.3、速度 +0.1 | 气血 +6、法伤 +0.3、速度 +0.1 | 气血（副：法伤、速度） |
| 魔力 | 魔法 +3、法伤 +0.7 | 魔法 +3.5、法伤 +0.7 | 魔法 +2.5、法伤 +0.7 | 法伤、魔法上限 |
| 力量 | 伤害 +0.75、法伤 +0.4 | 伤害 +0.65、法伤 +0.4 | 伤害 +0.85、法伤 +0.4 | 物理伤害（副：法伤） |
| 耐力 | 防御 +1.5、法伤 +0.2、速度 +0.1 | 防御 +1.6、法伤 +0.2、速度 +0.1 | 防御 +1.4、法伤 +0.2、速度 +0.1 | 物理防御（副：法伤、速度） |
| 敏捷 | 速度 +0.7、躲避 +1.0 | 速度 +0.7、躲避 +1.0 | 速度 +0.7、躲避 +1.0 | 速度、躲避率 |

- 战斗读的是派生后的值：`_make_player_team()` 把 气血/魔法/伤害/速度/防御/躲避/法伤 写进**战斗副本**
  （`.tres` 本身不动）。其中**防御 / 躲避 / 法伤 目前只算好、只展示** —— 战斗结算还没有减伤/闪避/法伤这一步；
- 二级属性（暴击率 / 暴击伤害 / 封印命中率 / 治疗量 / 抗暴击率 / 爆伤减免 / 抵抗封印 / 格挡值）也在
  `UnitStats` 上有字段、会被 `derived_stats()` 带出来，但同样是**只展示**（战斗里暴击固定 10% + ×1.5、
  格挡是全额免伤，都还没读这些字段）。
- 属性面板（`C`）里 5 项基础属性带「＋」按钮，点一下扣 1 点自由点、数值与派生属性立刻刷新
  （面板内容现在放在滚动区里，行多了也不会顶出屏幕）。
